## 这轮实验的含义

本轮是**同证据、禁外部工具的工作流对照**。图检索在准备阶段真实执行，之后双方读取完全相同的冻结结果。图谱关系包含法源节点查找、显式章节引用和同 Part 邻接，不代表语义蕴含。原始基准证据仍保留。最终引用中 A 使用 8 个向量证据 ID、B 使用 6 个；双方都没有返回 `graph:` 引用 ID。因此本轮验证图谱接入与证据输送，不能证明模型依赖图谱得到正确答案，也不是端到端检索召回率测试。

原生 CLI 已真实接通，但当前转接层仅支持文本，Lawgent 的 provider 也未执行外部工具循环；不能据此宣称完整自主 Agent 的全部能力。双方系统指令与调用次数仍有差异，这属于当前工作流处理差异。每次输出预算相同不等于每题总 Token 相同，成本与调用次数必须一起看。

按用户要求，本轮不加强法律评测器。答案仍使用标签、选项及子串/词重叠规则；引用仍以首条引用、法域、日期及关键词为主。综合通过表示通过这些规则，不能替代专家法律判断。
